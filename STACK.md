## Development Environment

### Build Instructions

```bash
# Configure with CMake
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Build all targets
cmake --build build --config Release

# Run tests
cmake --build build --target test

# Install to system
 cmake --build build --target install
```
